# Assets

Images, icons, illustrations and fonts used on the website. SVG files open in the browser when you click them.

| Folder | What's in it |
|---|---|

| [graphics/](graphics/) | Spot illustrations for topics such as UX audit, design systems and white label |
| [images/](images/) | Photos and pictures: team members, industries, success stories, insights |
| [logos/](logos/) | Client logos for the "trusted by" strip |
| [fonts/](fonts/) | Font files (Manrope and Besley) |

Which graphic to use where, and how to draw a new one: [docs/GRAPHICS.md](../docs/GRAPHICS.md).
