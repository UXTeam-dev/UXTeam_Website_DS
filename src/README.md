# Source

The code that people edit: page bodies, ready-made sections, and the site's styles. The build turns this folder into finished files in `dist/`.

| Folder | What's in it |
|---|---|
| [pages/](pages/) | One file per page (the main content between the header and footer) |
| [partials/](partials/) | Ready-made sections and elements that pages are built from |
| [starters/](starters/) | The blank page every new page starts from |
| [global/](global/) | The booking card and footer, which appear on every page |
| [css/](css/) | The site's styles, the same ones the live site uses. How styles are written and where they go: [docs/CSS-GUIDE.md](../docs/CSS-GUIDE.md) |

How to work here: [LLM.md](../LLM.md) and [docs/CSS-GUIDE.md](../docs/CSS-GUIDE.md).
