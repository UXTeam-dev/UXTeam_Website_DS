# Sections and elements

Ready-made building blocks, copied from the live site. A new page is put together from these, changing only the text, links and images.

| Folder | What's in it |
|---|---|
| [sections/](sections/) | Whole page sections: hero, services, process, success stories, FAQ, client logos and more |
| [elements/](elements/) | Small pieces used inside sections: buttons, headings, FAQ items, image placeholders |

What each one looks like and how to use it: [docs/COMPONENTS.md](../../docs/COMPONENTS.md).
