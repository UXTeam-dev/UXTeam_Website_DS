# Pages

One file per page of the website. Each holds only the page's main content: the header, booking card and footer are added by WordPress.

| File | Page |
|---|---|
| `homepage.html` | Homepage, built by the developers |
| `what-we-do.html` | What we do, built by the developers |
| `white-label.html` | White label, built in this repo |

To see a page, look at [new.ux.team](https://new.ux.team) or the approved designs in [reference/pages/](../../reference/pages/). Developers can make a preview with `npm run build`, or a file to share with `npm run share -- <page>`.

To add a page: [LLM.md](../../LLM.md) sections 15 and 16.
