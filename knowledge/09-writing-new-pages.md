# Writing a page that has no content

How to build copy for a new page (About, Contact, Industries, How we work, UX Audit, Insights, a service page) from what UXTeam has already published, without inventing facts.

## The order

1. **Page job and structure:** [../docs/BRAND-GUIDE.md](../docs/BRAND-GUIDE.md) section 8 (Page rules) gives the job, must-haves and main action.
2. **Facts:** pull from this folder using the map below. Prefer exact live wording for names, services, platforms and processes.
3. **Proof:** one or two items per claim from [04-success-stories.md](04-success-stories.md) and [05-testimonials.md](05-testimonials.md).
4. **Numbers:** only those marked safe in [07-numbers-and-claims.md](07-numbers-and-claims.md).
5. **Voice:** rewrite everything into the brand guide's voice (sentence case, plain, "you", no em dashes, avoid list). Live wording is a fact source, not a style source.
6. **Gaps:** anything still missing stays a visible placeholder like `[confirm with Chintan: …]`. Never fill it with a plausible guess.
7. **Sign off:** final wording goes to Chintan.

## Checklist before handing over a page

- [ ] Every fact traces to a file in this folder or the brand guide.
- [ ] Every number is on the safe list in [07](07-numbers-and-claims.md), with what it measures.
- [ ] No issue from [08](08-content-issues.md) was copied across.
- [ ] Agency wording appears only on agency pages.
- [ ] Sentence case, no em dashes, no avoid-list words, American spelling.
- [ ] One main CTA per screen: "Book a Discovery Call" (or "Start with an audit" on the audit page).
- [ ] Placeholders are visible and marked `[confirm …]`.
